# 美分马丁-stable 安全系数与参数网格测试总结

> 适用 EA：`美分马丁-stable.mq5`（v1.8 逻辑）
> 数据区间：2024-09-16 ~ 2026-11-06（约 2.14 年），XAUUSD M1
> 本文件为分析记录，**不涉及 EA 代码修改**。
> 最后更新：加入周一开盘 / 周五收盘禁开仓规则，修正 broker 时区（跟随欧洲夏令时），网格重跑。

## 一、分析目标与整体思路

**核心目标：生存优先，其次才是收益。**

真实账户经历：9-16（-$327，无满层强平时被动爆仓）、9-22（-$77）、9-11（-$60）、11-03（-$145，满层强平截断）。账户余额从投入的 $600 降到 $250，累计亏损约 -$350。因此先回答"能不能扛住"，再讨论"能赚多少"。

**两条优化路线：**

| 路线 | 思路 | 代价 |
|---|---|---|
| A 扛得更久 | 加宽 `LossPriceGap`，同样 22 层覆盖更大单边；或加本金 | 收益下降，单次亏损变大 |
| B 别往坑里挖 | 速度闸门（快速逆行时只平不加）、深层止盈递减、浮亏硬止损 | 实现复杂，需样本外验证 |

**决定：** 用户接受本金增加到 600u 以下，优先用安全系数指导参数选择。收益侧留待下一步。

## 二、安全系数的定义（已与用户对齐）

| 项目 | 定义 |
|---|---|
| 爆仓 | 保证金比例（净值 / 占用保证金）跌破停损线 50%，**裸爆仓，不启用满层强平** |
| 起点 | 每根非平盘 M1 都作为起点，做多、做空各模拟一次，**不依赖 MA 信号** |
| 禁开仓 | 周一开盘后 3 小时、周五收盘前 3 小时内**不建仓**（见 3.4），已有篮子照常止盈和判爆仓 |
| 篮子 | 首单 L1，按 gap 逐层加仓，回本由 EA 均价差 TP 决定 |
| 悲观路径 | 每根 K 线内先走不利方向极值，再走有利方向 |
| 独立事件 | 同方向爆仓起点按 6 小时间隔聚类，计为一次事件 |
| 新闻扣除 | 爆仓路径 [起点, 爆仓时刻] 与事件 ±60 分钟窗口有交集则扣除 |
| 年化 | 独立事件数 ÷ 2.14 年 |

**输入：** 本金、gap（USD/oz）、TP（USD/oz）

**输出：**
1. 支持层数（动态推算）
2. 理论爆仓点数（做空 / 做多，参考价 4300）
3. TP 回撤点数（最后一层开仓后，价格要回撤多少点才能触发全平）
4. 独立事件数（未扣新闻 / 扣新闻）
5. 每年事件数
6. 实际爆仓中位不利距离（与理论值并列显示）

## 三、关键规则

### 3.1 动态层数
第 n 层位于 `(n-1) × gap`。若理论爆仓点 ≥ `(n-1) × gap + 缓冲`，则允许开第 n 层。
- 缓冲取 **2 点**（用户确认）。缓冲为 0 时 300u/gap2.5 会卡在第 23 层的边界上，结果没有参考价值。
- 层数上限 60 层（脚本保护值，非业务规则）。
- 第 22 层之后手数按 EA 的 L13+ 规则延伸：前一层 × 1.3，向下取整到 0.01。延伸部分只用于测试。

### 3.2 理论爆仓点数
只看加仓和保证金，不含 K 线跳空和点差的实际成交偏差。
- 每层成交价 = 上一层 - (gap - 点差)，即**实际间距 = gap - 0.20**
- 保证金 = 占用手数 × 价格 / 500

### 3.3 TP 回撤点数
`最后一层开仓价 - 篮子均价 + TP + 点差`

### 3.4 禁开仓时段（新增）
- 周一 01:00–04:00（broker 时间）与周五 20:59–23:59 禁止新开单（首单和加仓）。
- 只针对周一开盘和周五收盘，**不含每日停盘**（每日 23:59–01:00）。
- 已有篮子的止盈和爆仓判定照常进行。
- 时段由数据推出（周五 23:59 收盘、周一 01:00 开盘），**请以 Decode 官方交易时间为准**。

### 3.5 broker 时区（修正）
broker 服务器时间**跟随欧洲夏令时**：
- 夏令时（3 月最后一个周日 ~ 10 月最后一个周日）：broker = UTC + 3
- 冬令时：broker = UTC + 2

修正前曾错误地使用固定 UTC+3，导致**冬季（约 11 月至次年 3 月）的时间标注比实际晚 1 小时**，并使禁开仓规则在周六误触发。修正后每周收盘稳定在周五 23:59、开盘在周一 01:00。

## 六、验证结果

### 6.1 9-16 真实爆仓复现
模拟在 2026-09-16 06:16 复现空单爆仓，最大不利 56.0 点。真实账户为 06:22 结束，中位不利距离与理论值一致，方向一致。

### 6.2 四次真实大亏窗口检查（300u，gap 2.5，TP 0.6）

> **注意：本表是修正前（固定 UTC+3、无禁开仓）的结果，需要重跑。** 9-16、9-11、9-22 在夏令时，时间标注不受影响；11-03 在夏令时（10 月末前）之后的 11 月，时间标注需要减 1 小时。

| 窗口 | 起点数（多+空） | 爆仓 | 真实情况 |
|---|---|---|---|
| 9-16 04:30–06:30 | 242 | 1（空） | 真实爆仓 |
| 9-11 06:30–08:30 | 242 | 0 | 真实为旧版 L14 浅套止损 |
| 9-22 07:00–09:30 | 302 | 0 | 震荡市，篮子反复平仓 |
| 11-03 13:30–15:00 | 182 | 0 | 真实为满层强平截断 -$145 |

**说明：** 11-03 的 72 点单边中途有 9 点以上回撤，满篮子被 TP 平掉，裸模拟不会爆仓。这说明裸爆仓口径和"单边 72 点"的直觉不完全一致，单边的连续性比幅度更重要。

### 6.3 层间距核对（11-03 真实卖出篮子）
相邻层成交价差多数在 2.2–2.4 之间，与 `gap - 点差 = 2.3` 吻合。L9→L10 有一次 5.8 点跳空（异常值）。**结论：实盘实际间距被点差压缩，应按 gap - 点差建模。**

### 6.4 禁开仓规则的回归检查
- 关闭禁开仓（`--no-session`）：600u / gap 3.25 / TP 0.5 / 24 层，15 次爆仓。
- 开启禁开仓，修正时区后：15 次爆仓，结果一致。
- 修正时区前开启禁开仓出现 44 次，其中 35 次起点在周六（市场不交易），由时区错误造成。

### 7.5 主要发现
1. **本金、gap 和 TP 都影响安全系数。** 同一本金和 gap 下，TP 从 0.5 到 1.5，事件数变化很大（300u：gap 2.5 时相差 32 次，gap 1.0 时相差 205 次）。TP 越大，篮子等待回本的时间越长，暴露越久，爆仓越多。因此 TP 不能只当作收益参数，必须和 gap 一起评估。（原文"TP 几乎不影响"是错误结论，已更正。）
2. **动态层数变化很小。** 全部 572 组的支持层数在 21–25 之间，本金翻倍只增加 1–2 层，因为理论爆仓点随 gap 同步增长。
3. **gap 越大，TP 回撤点数越多。** gap 4.0 需要回撤约 13 点才能平仓，解套时间变长，收益会下降。这是安全与收益的主要取舍。
4. **gap 2.5 以上事件数大幅下降**，gap 1.0 时每年 40–70 次，完全不可接受。
5. **排名靠前的组合样本极少。** gap ≥ 3.5 的每组只有 1–7 次事件，排名变化很大（修正前后 600u / gap 4.0 / TP 0.6 从 5 次变为 3 次）。不能只靠这个排名选参数。

## 八、已知问题与未解决事项

### 8.1 周末跳空（待决定）
- 2026-01-02 与 2026-02-27 两次爆仓，都是周五开仓后跨周末，周一开盘跳空 +29 和 +95 点。
- 禁开仓只限制新开单，**已有篮子仍会持仓过周末**。
- 候选方案：周五收盘前平掉所有篮子（需要你决定，并会增加交易成本，也会影响收益侧）。

### 8.2 数据异常（待核对）
- 2026-01-29 17:20–17:35（broker 时间）：6 分钟内价格从 5358 跌到 5098，单根 M1 振幅 134 点。
- 数据来源是 `xau-breakout-guard` 的第三方 parquet，不是 broker 报价。
- 需要用 XAUUSD.ct 图表核对。若确认为坏 tick，应从统计中剔除，事件数减为 6 次。
- 另外，这类穿仓（亏损超过本金）模拟器没有建模，实盘会负余额。

### 8.3 liq_planner.html 与模拟器的 TP 回撤差 0.46 点（未修改）
- planner：层间距直接用 gap，TP 回撤不含点差。300u/gap2.5 为 **8.78**。
- 模拟器：层间距为 gap - 点差，TP 回撤含点差。同配置为 **8.33**。
- 用 11-03 真实成交核对，实际间距约 2.3，**模拟器正确，planner 高估**。
- 修正方向：planner 应改为层间距 = gap - 点差，并加点差输入框（默认 0.20）。
- **用户决定暂不修改 planner，保持现状。** 因此两边数字在 TP 回撤上仍相差约 0.46 点，使用时需注意。

### 8.4 "36 次"的来源未找到
用户之前跑过类似分析记录为 36 次，本次未能复现。已测试的口径：
- 聚类间隔 0–24 小时、扣新闻与否：16–85（修正前）
- 停损 30%、点差 0.35、超时 1 天 / 7 天：13–33（修正前）
- 用户的《美分马丁策略完整分析报告》（Huali Wu 账户，2026-07）只统计了深扛翻盘，没有爆仓次数统计。
- 结论：**36 的口径未确认，不能据此判断对错。** 需要用户提供当时的脚本或参数。

### 8.5 其他限制
- **停损线 50% 未确认。** 这是影响最大的参数，需要核实 Decode 的 Stop-Out 设置。
- **禁开仓时段由数据推出**，需对照 Decode 官方交易时间。
- **点差固定 0.20，未建模新闻前后的扩大。** 实盘真实爆仓可能比模拟更早。
- **样本量小。** 数据约 2.14 年，gap ≥ 3.0 的每组只有 1–7 个事件，统计误差很大。排名靠前的组合需要样本外验证。
- **新闻日历只有四类。** 实际爆仓中只有少数落在窗口内，说明大部分爆仓不由这四类事件引起，"避开金融事件"并不能显著降低爆仓率。
- **K 线过冲。** 实际爆仓中位不利距离比理论值高约 4–6 点，因为价格跳过停损线时会在更差的价位平仓。
- **穿仓未建模。** 跳空或坏 tick 可能让亏损超过本金，模拟器只记到停损线。
- **悲观假设。** 同一根 K 线内取最不利顺序，会略高估爆仓次数。
- **收益侧未计算。** 本次只做了安全侧，没有计算净收益。

## 九、下一步建议

1. **核实 Decode 的停损线**（Stop-Out 水平）。该值变化会直接改变全部理论爆仓点和事件数。
2. **核实 Decode 官方交易时间**，确认禁开仓时段。
3. **决定周末跳空的处理**（见 8.1）。
4. **核对 2026-01-29 数据异常**（见 8.2）。
5. **决定 planner 是否修正**（层间距与点差），以保证两边的 TP 回撤一致。
6. **收益侧分析**：在同一网格上计算每年净收益（止盈收益减去爆仓损失），与安全系数一起比较。
7. **样本外验证**：对 gap ≥ 3.0 的候选组合，等待更多实盘数据或补充更早的历史数据。
8. **重跑 6.2 节窗口检查**（修正时区后）。
9. **解决 36 次的口径问题**：如果用户能提供当时的脚本，可以直接对齐。
