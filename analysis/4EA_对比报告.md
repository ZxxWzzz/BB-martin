## 💡 关键洞察

### 1. "浅层繁荣 + 深层灾难" 模式统一
所有EA都是:
- **L1-L6 100% 胜率** (除V2A的L1有1笔$0)
- **L7+ 一旦真触发就是爆仓** ($1000-2600 单次亏损)
- **单次爆仓抹掉 30-100 笔浅层盈利**

### 2. "扛点能力"是活下去的唯一指标
```
V3GPT   扛96点 → 08-05 单边>96点 → 爆
V3GPTL  扛84点 → 08-05 单边>84点 → 爆
V2B     扛86点 → 08-05 单边>86点 → 爆
```

### 3. 高胜率是假象
```
V3GPT 胜率98.4% → 净亏 -$1,212
V3GPTL 胜率98.3% → 净亏 -$1,100
V2A 胜率97.4% → 净亏 -$4,530
```
**97% 以上胜率毫无意义**，只要一次爆仓就全没了。

### 4. 深层单笔盈利被极端爆仓完全掩盖
```
V3GPTL L4 一笔 +$254.83 (极佳单笔)
但 L9 一笔 -$2,634 (抹掉10次以上L4)
```
