📂 如何找到 EA 交易文件

方法1: 使用 MT5 内置快捷方式 (推荐)

  1. 打开 MT5
  2. 顶部菜单 文件 → 打开数据文件夹
  3. portable 模式: 进入 MQL5\Files\
  4. 普通模式: 需在文件夹地址栏点击 Terminal → 进入 Common\Files\

方法2: 直接粘贴路径 (Windows)

  1. 打开资源管理器(Win+E)
  2. 在地址栏粘贴: %APPDATA%\MetaQuotes\Terminal\Common\Files
  3. 回车即可到达

方法3: 在本项目 portable 副本中

  1. V2A: D:\MT5s\MetaTraderV2A\MQL5\Files\
  2. V2B: D:\MT5s\MetaTraderV2B\MQL5\Files\
  3. V3GPT: D:\MT5s\MetaTraderV3GPT\MQL5\Files\
  4. V3GPTL: D:\MT5s\MetaTraderV3GPTL\MQL5\Files\
  5. ⚠️ 但由于 EA 用了 FILE_COMMON 标志,实际写入的是 Common\Files 共享目录
