## 三、策略机制(EA 源码 + 订单交叉验证)

### 触发框架
- **指标**：M30 周期自定义指标 `小艺2` (iCustom 返回 +/-/0)
- **方向切换**：iCustom 符号变化 → `CloseAllOrders()` + `ResetState()`
- 全部裸单 (SL=0, TP=0), 平仓全靠 EA 主动发指令

### 开仓逻辑
```
指标信号 (M30)
    ↓
无持仓 → 开 L1 = base × 1手
有持仓 → 逆向 ≥ 200 points (=$2.0)? → 加 L(n+1)
```

### 平仓三通道
1. **方向翻转** → `CloseAllOrders()` (主导,集群批量平仓)
2. **单向止盈** (SingleTakeProfit) → 该方向利润≥阈值时平该方向
3. **整体止盈** (TotalTakeProfit) → 多空总利润≥阈值时全平

### 无止损
- `StopLossAmount = 0`
- 依靠"扛到方向翻转"翻盘,是经典马丁范式

## 八、跟单模式说明

### Statement 里的 `copy #xxxxx` 是什么

**MT4/MT5 官方社交跟单 (MQL5 Signal Service)** 订单标签:
```
copy # <SubscriberTicket> / <RetryCount>
```

```
┌──────────────────┐               ┌────────────────────┐
│  信号发布方 (Master) │  ─── 官方 ─→ │ 订阅方 (Slave)      │
│  跑真正的 EA        │   MQL5 云端  │  账户 30002558      │
│                    │   信号中转   │  Huali Wu#3         │
└──────────────────┘              └────────────────────┘
```

Master 端每单发 0.01 手,订阅端设置**放大系数 13/14/15** → 本地成交 0.13/0.14/0.15 手 = 三条并行主线的来源。

### 两种落地方式

| 路线 | 说明 | 优点 | 缺点 |
|---|---|---|---|
| **A. 直接订阅** | MT5 客户端 Signals 面板订阅 Master | 零开发,官方保证同步 | 订阅费,策略黑盒,无法插自己风控 |
| **B. 自研 EA** | 参照 `参照马丁.txt` + 校正手数序列 | 完全自主,可加风控 | 需拿到 M30 "小艺2" 指标源码 |

当前 `bb-martin-monitor` 项目走的是路线 B (布林带马丁 V1-V4 自研),并在 TODO 中规划了 EA 未有的黑天鹅熔断/流动性暂停/50% 强平等强化风控。

## 十、风险评估

### 结构性优势
1. **趋势跟随 + 逆势加仓的混合体**:方向由指标锁定,间距逆价才加仓
2. **靠"方向翻转 = 强制平仓"触发翻盘**:不等价格回到成本,等指标反转顺势收网
3. **对高频震荡效率极高**:L1 独立止盈占 66%,均盈亏 +5.74 USC

### 脆弱性
1. **L22 = 弹药上限**:CENT22 参数只算到 22 层,再深无救兵 → 爆仓
2. **最深加仓 = 42 点** (21 层 × 2 点),金价常见 20-30/日,数据日 50-80
3. **base=0.15 源过早止损**:破坏了马丁"回本承诺",单月亏 −17,122
4. **7 月最大回撤 9.43% 是运气好**:每次深扛都在 4155 附近有强回摆
